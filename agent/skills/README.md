# skills/

`<name>/SKILL.md` with `name` and `description` in the front matter. The description is all
the agent sees until a task matches; the file is read only then. Keep it precise — it is the
entire basis for the decision to load it.

A skill is for *procedure* ("how we handle a refund request"). Facts belong in
`knowledge/notes/`, where they are searched rather than loaded.
